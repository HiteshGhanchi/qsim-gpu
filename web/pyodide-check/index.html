qsim-gpu in the browser

Not the website: a test page. It loads Pyodide, installs the qsim-gpu wheel from dist/, runs the same workload as scripts/compare_pyodide.py, times the NumPy backend at 10, 14 and 18 qubits, and probes how many qubits fit. Serve this folder over HTTP (for example python -m http.server) after copying the built wheel into dist/.
