# Changelog

All notable changes. Versions follow [semantic versioning](https://semver.org/): while the
version is 0.x, minor releases may change the public API.

## [Unreleased]

## [0.2.0] - 2026-11-27

### Added
- Mid-circuit measurement, reset and classical conditions (`Circuit(n, n_clbits=...)`,
  `measure`, `reset`, `c_if`), with identical results on both backends for the same seed;
  `run_shots`; teleportation and 3-qubit bit-flip code demos.
- Step-by-step execution: `Backend.run(circuit, on_step=...)`, and `qsimgpu.views` with marginal
  probabilities (GPU reduction kernel), Bloch vectors, snapshots and a versioned JSON step trace.
- OpenQASM 2 import and export (`from_qasm2`, `to_qasm2`), written by hand; optional Qiskit
  bridge and OpenQASM 3 through Qiskit (`qsimgpu.interop.qiskit`).
- Gates `u`, `sx`, `sxdg`.
- Benchmarks: bandwidth sanity check in every result, results stored per GPU, README tables
  generated by `bench/report.py`, Kaggle T4 runner; Tesla T4 results.
- Public API exported from `qsimgpu`, `py.typed`, this changelog, a release workflow.

### Changed
- The import package is now `qsimgpu` (was `qsim`, which is taken on PyPI).
- `import qsimgpu` needs only NumPy. scipy moved to the `vqe` extra; matplotlib was dropped.
  GPU extras: `gpu-cuda12` and `gpu-cuda13` (`gpu` still means CUDA 12).
- `Backend.run` returns the classical bits and accepts `on_step` and `rng`.
- Default gate-fusion width is 2 (was 3), the best width measured on a healthy GPU.
- The simulator comparison (B7) is fair: same returned value, full state on every engine,
  fusion on and off, 7 repeats.

## [0.1.0] - 2026-11-19

### Added
- Gate set, circuit IR, NumPy reference backend, CUDA backend with general and specialised
  kernels, gate fusion, sampling, Pauli expectations; GHZ, Grover, QFT, Shor (N = 15) and VQE
  for H₂; benchmark suite.
